# VBA report comparison

Макрос для сверки двух Excel-отчётов по ключам `Компания` и `Документ`.

## Что делает
- создаёт композитный ключ `Компания|Документ`;
- находит дубликаты внутри каждого отчёта;
- сравнивает записи между файлами;
- помечает расхождения жёлтым цветом;
- помечает отсутствующие строки красным;
- пишет лог в `log_sverka.txt`;
- восстанавливает настройки Excel после выполнения.

## Требования
- в Excel должны быть открыты файлы:
  - `Отчёт1.xlsx`
  - `Отчёт2.xlsx`
- макрос запускается с первого листа каждого файла.

## Как использовать
1. Откройте VBA редактор: `Alt + F11`.
2. Создайте новый модуль.
3. Вставьте код из файла `CompareReportsHybrid.bas`.
4. Запустите макрос `CompareReportsHybrid`.

## Результат
После выполнения макрос показывает итоговую статистику:
- совпадения;
- расхождения;
- отсутствующие записи;
- количество дубликатов в каждом отчёте.
